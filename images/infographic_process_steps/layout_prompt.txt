# HTML/CSS再現プロンプト

レイアウト:
- 背景: #F7F8F6 の淡いグレー
- 最大幅: 1400px、中央寄せ
- タイトルを中央配置。「完全非対面・郵送のみの3つのステップ」
- サブコピーをタイトル下に配置
- 3カラム(equal width, gap 32px)
- 各カード:
  - 白背景
  - border-radius:24px
  - box-shadow:0 10px 30px rgba(0,0,0,.08)
  - padding:32px
  - 左上に濃緑(#0F5A3A)のSTEP円
  - アイコン中央
  - 見出しは太字
  - チェックリストを縦配置
  - 下部に淡いクリーム色(#FFF6DA)の補足ボックス
- カード間は緑色矢印で接続
- 最下部に横長の注記ボックス
- PCでは3列、768px以下では1列に切替
- フォント: Noto Sans JP
- メインカラー: #0F5A3A
- アクセント: #D18A00 と #D53A2F
