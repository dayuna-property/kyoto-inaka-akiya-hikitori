# 不動産三社連携図解：LP用アセットキット

このキットは、提供された1枚の図解をLP上で再利用できる単位に切り分けたものです。

- `assets/`：PNG素材（素材ごとに外周の白背景を透明化）。
- `assets/10_family-photo-area.png`：実写風家族写真の矩形配置用素材。写真内の背景は意図して保持しています。
- `assets/03_...`, `05_...`, `07_...`：各社のパネル。枠内の白地はパネルの一部として保持しています。
- `assets/16_trust-badges-full-strip.png`：4つの信頼バッジを一体で使う場合の素材です。各バッジは12〜15としても個別に収録しています。
- `layout-recreation-prompt.txt`：画像モデルでレイアウトとテイストを再現するための詳細プロンプトです。
- `reference-original-infographic.png`：切り分け元の参照画像です。

透明化は「外周から連続する白」だけに適用しています。そのため、パネル・書類・CTA内の白は正しく残ります。
